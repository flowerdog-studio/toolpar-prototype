# Toolpar — передача дизайна в разработку

Эта папка описывает финальный дизайн интернет-магазина Toolpar (tssp.kz) для переноса в продакшн. Если что-то выглядит неоднозначно, сверяйтесь с источниками в таком порядке:

1. **Интерактивный прототип** (`dev-dfc314/index.html`) — эталон поведения и мобильной вёрстки. Его можно открыть по ссылке или локально, см. ниже.
2. **Figma «Toolpar DS»** — токены, текстовые стили, компоненты и их состояния, макеты веб-страниц. Страница *Getting started* в файле объясняет, как подключить библиотеку.
3. **Эта папка** — правила, спецификация страниц и чек-лист переноса.

Прототип — это не код для продакшна. Это один HTML-файл с демо-данными, без сборки, роутинга, SEO и бэкенда. Из него можно напрямую брать **токены, CSS-значения, размеры, тексты и логику поведения**, а разметку и скрипты нужно переписать компонентами вашего стека (сейчас tssp.kz работает на Nuxt/Vue).

## Что в папке

| Файл | Что внутри |
|---|---|
| `tokens.css` | Готовые CSS-переменные (цвета, отступы, сетка, кегли с мобильным режимом) и классы текстовых стилей `.t-*`. Подключать первым. |
| `tokens.json` | Те же токены в JSON — для Tailwind, Style Dictionary и т. п. |
| `design-system.md` | Правила системы: цвет, типографика, сетка, отступы, иконки, состояния, тексты. |
| `components.md` | Компоненты: имя в Figma ↔ класс/функция в прототипе ↔ состояния и поведение. |
| `pages.md` | Все страницы: секции, поведение, отличия мобильной версии, ссылки на скриншоты. |
| `production.md` | Как переносить: порядок работ, что брать из прототипа, данные, SEO, доступность, производительность, приёмка, открытые вопросы. |
| `screens/` | Полностраничные скриншоты прототипа: `desktop-*.jpg` (1440) и `mobile-*.jpg` (375 @2x). |
| `skill/toolpar/SKILL.md` | Навык для Claude: с ним Claude продолжает работу по тем же правилам. Его можно загрузить в Claude в разделе навыков (Skills) в настройках или положить в `.claude/skills/toolpar/` проекта для Claude Code. |

## Как запустить прототип локально

```bash
cd dev-dfc314
python3 -m http.server 8000
# открыть http://localhost:8000
```

Ширина окна до 767 px включает мобильную версию: вместо адаптивной вёрстки там рендерится отдельное дерево компонентов с префиксом `M`. Посмотреть её можно в DevTools → Device Mode → iPhone.

## Структура прототипа

| Путь | Назначение |
|---|---|
| `index.html` | Всё: CSS (токены → компоненты → мобильная версия), три `<script>` (веб, мобилка, корзина и ЛК + новые страницы). |
| `content.json` | Каталог для демо: категории, главная, товар (данные с tssp.kz). |
| `img/c/*.json` | Товары по категориям для страниц каталога. |
| `help.json` | Тексты раздела «Покупателям»: хаб, «Как сделать заказ», «Доставка», «Оплата», «Обмен, возврат, гарантия». |
| `idmap.json` | Сопоставление id категорий. |
| `img/banners` | Баннеры главной (веб и `-m` мобильные кропы) и акций. |
| `img/about` | Фото «О компании»: `hw.jpg/hw@2x.jpg` — шапка веба, `about-m*.jpg` — мобильный кроп 4:5, история, команда, `partners/` — логотипы клиентов. |
| `img/loyalty` | Баннер «Системы привилегий»: `hero.jpg`, `hero@2x.jpg` (веб), `hero-m.jpg` (мобилка). |
| `img/help` | Скриншоты шагов «Как сделать заказ». |
| `img/brands`, `img/p` | Логотипы брендов, фото товаров. |
| `media` | Рилсы (mp4 + постеры). |

Ключевые функции в `index.html`: `render()` и `go(view, id)` — переключение экранов веба. `mRender()` — то же для мобилки. Страницы — `Home`, `Category`, `Product`, `Cart`, `Order`, `HelpHub`/`HelpPage`, `PromosPage`, `BrandsPage`, `Thanks`, `AboutPage`, `LoyaltyPage`. Мобильные — `MHome`, `MCatalog`, `MCategory`, `MProduct`, `MFilters` и т. д. `typo()` ставит неразрывные пробелы после коротких слов.
